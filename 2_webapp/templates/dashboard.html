Clé SSH publique

Avec une clé enregistrée, vos machines n'acceptent que cette clé en SSH — jamais un mot de passe.

{{ 'Clé enregistrée' if ssh_public_key else 'Aucune clé' }}

Générez-la avec ssh-keygen -t ed25519 puis collez le contenu de ~/.ssh/id_ed25519.pub. Laissez vide pour la supprimer.

S'applique aux prochaines machines louées.

Se connecter à une machine

Trois façons{% if tls_machines %}, chiffrées en TLS{% endif %}.

1

Terminal

Dans le navigateur, une invite de connexion comme sur une console : tapez root, Entrée, puis le mot de passe (invisible à la frappe) et Entrée.

2

Bureau

Pour les machines en mode bureau : XFCE et Firefox dans le navigateur. Mot de passe VNC = les 8 premiers caractères du mot de passe root.

3

SSH

Copiez la commande de la machine. Avec une clé enregistrée la connexion est immédiate ; sinon, saisissez le mot de passe.
