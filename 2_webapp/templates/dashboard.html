Accéder à une machine

Trois façons{% if tls_machines %}, chiffrées en TLS{% endif %}.

  1. Terminal — dans le navigateur, une invite de connexion comme sur une console : tapez root, Entrée, puis le mot de passe (invisible à la frappe) et Entrée.
  2. Bureau — pour les machines en mode bureau : XFCE et Firefox dans le navigateur, mot de passe VNC = 8 premiers caractères du mot de passe root.
  3. SSH — copiez la commande ; avec une clé enregistrée la connexion est immédiate, sinon saisissez le mot de passe.
